How It Works

Animated explainers for how software really works.

How It Works is a library of step-by-step animations that show what happens inside the systems you use every day: networks, protocols, browsers, servers and databases. Each explainer plays like a short film you control, with every message drawn as it moves between the machines involved.

  • Computer science students
  • Developers and engineers
  • Interview and exam preparation
  • Anyone curious about how the internet works

What every explainer gives you

  • See it

    An animated diagram

    The systems involved, laid out where they live, with each message travelling between them.

    Request Response Encrypted
  • Understand it

    A plain explanation

    What happens at each step and why, in clear language that still uses the correct technical terms.

  • Go deeper

    Under the hood

    Protocol details, the real message contents, and the practical consequences for performance and security.

  • Try it

    A command to run

    Something you can run on your own machine to see it happen, like dig, curl -v or openssl.

How to watch

  • Go at your own pace

    Press Next, use ← →, or swipe the diagram on a phone. Each step replays its animation.

  • Or press Play

    Play runs every step automatically, pausing long enough to read each one. Change the speed with the 1× button.

  • Go deeper

    Under the hood shows the protocol details, the real message contents, and a command to try it on your own machine.
